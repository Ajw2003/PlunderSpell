# Design

Tier 7: what the game is meant to be. The pitch bible, the designs that are still live, and every
current visual reference, in one place (owner, 2026-10-11). How the built game works is tier 4
([`4-systems`](../4-systems/README.md)); a plan for building one piece of work is in
[`docs/plans/`](../plans/).

A design leaves this folder for [`docs/archive/`](../archive/README.md) once it no longer describes
the game we are making.

- [`plunderspell.md`](plunderspell.md) — the pitch and design bible (v0.2), written to be read
