# Roadmap

Full technical doc: [Roadmap.md](../../2-roadmap/Roadmap.md)

## What it is
The four milestones the project is built toward, and what counts as finishing each.

## Why it matters
Without a fixed definition of "done", progress becomes opinion.

## How it works
1. Restore normal gravity after forking from an earlier project.
2. Prove speaking spells feels good, with real people on a real microphone.
3. Get the whole loop working for four players in one castle, finishing a raid.
4. Let a chosen age visibly change a raid's rooms, loot, enemies and weapons.

## Risks and safeguards
- **A milestone called finished from a unit test alone.** Several need real people.
- **"Done" drifting over time.** This changes only with the definition.
