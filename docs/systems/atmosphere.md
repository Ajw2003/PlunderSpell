# Atmosphere: the castle at night

The castle's look: night, warm fire glowing in fog, a faint moon, and a castle that brightens and
reddens with each alarm state. Spec: `docs/plans/night-atmosphere.md`. Built on
`claude/night-atmosphere` (2026-09-25). Assembly `Plunderspell.Atmosphere`; editor tools in
`Plunderspell.Editor`.

## How it works

- **`CastleAtmosphere`** (`Assets/_Project/Scripts/Runtime/Atmosphere/CastleAtmosphere.cs`) blends
  four `AtmosphereLook`s (`NightAtmosphereProfile`, one per `AlarmState`) over 2 s on
  `AlarmFSMManager.AlarmStateChanged`. It drives fog globals, moon, trilight ambient, the night sky
  material, four graded Volumes (weights = state weights), per-era stone/flame tints
  (`_PlunderStoneTint`), every `FireSource`, and the fire light budget. Nothing is networked: each
  peer blends from the replicated alarm state.
- **Fog** is one full-screen Render Graph pass, `NightFogFeature` + `Hidden/Plunderspell/NightFog`,
  after opaques. Height fog plus closed-form point-light in-scattering
  (`Assets/_Project/Shaders/Atmosphere/NightFogCommon.hlsl`) for the nearest burning fires, each
  dimmed while a linecast from the camera is blocked. Transparent flames/portal fog themselves
  with the same functions.
- **Fire.** The Blender builders register fire anchors (`castle_builders._fire`), `build_assets.py`
  writes `Assets/_Project/Data/Castle/CastleFireAnchors.json`, `CastleFireAnchorImporter` copies them
  into the three room registries and `CastleDressingSet`. `CastleFireSpawner` lights one
  `FireSource` per anchor per castle. `FireRules` decides lit/flare per state and shares shadowed
  / unshadowed lights by distance (2/4/8 shadowed, 16/32/all lit on Low/Medium/High).
- **Surfaces.** `Plunderspell/Surface` (`Assets/_Project/Shaders/Surface/`): palette colour,
  world-projected detail from `SurfaceDetail.png` (R stone, G wood, B iron, A cloth; generated by
  `Tools/AssetPipeline/make_detail_textures.py`), triplanar unless Low, grime at wall feet, SSAO,
  fire light in soft bands, warm shadow tint. `CastleSurfaceMaterials` switches castle FBX materials
  at import by pigment. `SurfaceConverter` moves spawned guards and loot onto it.
- **Bailey.** `CastleDressingPlanner` (own seed stream) dresses straight curtain cells, the gate
  yards, the sealed gate and carved courtyards from `CastleDressingSet`; the generator places them
  before the NavMesh bake.
- **Portal.** `PortalGlow` (`Assets/_Project/Scripts/Runtime/Atmosphere/PortalGlow.cs`) stands the
  lapis swirl and its own `FireSource` wherever the raid opened the portal. In the last minute it
  falters: it dims to 35 % and shrinks to 60 % with the clock, and gutters slowly on top
  (`PortalGlow.FalterStrength`). The gutter stays under one flash a second; the first version
  strobed at up to 4.6 a second, past the 3 a second photosensitivity guidance allows (#145).
  `NightAtmosphereTests.Test_TheClosingPortalNeverFlashesMoreThanThreeTimesASecond` counts them.
- **Quality.** Low/Medium/High URP assets in `Assets/Settings/`; `AtmosphereQuality` applies the
  saved level or the machine default (Deck → Low) before the first scene.

## Rebuilding

All from the live Editor (`bash Tools/Unity/eval.sh '<C#>'`):
`NightAtmosphereForge.BuildAll()`, `NightAtmosphereForge.InstallInOpenScene()` (then save the scene),
`CastleDressingForge.Build()`, `CastleFireAnchorImporter.Import()`,
`CastleSurfaceMaterials.ReimportCastleModels()`. Tuned numbers live in `Assets/_Project/Scripts/Editor/NightLooks.cs`.
Captures: `bash Tools/Unity/night_captures.sh <out dir> Calm HueAndCry`.

## Traps

- **Colours are sRGB.** Ambient, fog and sky colours in `NightLooks` are read as sRGB; entering
  linear-looking values made the night ten times too dark.
- **Never edit C# while the Editor is in Play mode.** A script reload mid-raid broke PurrNet's
  `bool` writer into endless recursion, froze the Editor and grew `Editor.log` to 6 GB
  (2026-09-25). `night_captures.sh` always exits Play mode.
- Embedded FBX materials only pass through `OnPreprocessMaterialDescription`, not
  `OnPostprocessMaterial`.
