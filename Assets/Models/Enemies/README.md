# Plunderspell enemy models

Generated by `Tools/EnemyForge`. Do not hand-edit anything in this folder — rerun the
build instead, or the next run will overwrite your changes:

```bash
python3 Tools/EnemyForge/build_enemies.py
```

How the pipeline works, and the invariants it guarantees, are in
`docs/4-systems/enemy-asset-pipeline.md`.

## What each enemy folder contains

```
<Name>/
  <Name>.fbx              # game-ready mesh + rig, Unity axes (Y up, Z forward)
  <Name>.blend            # editable source
  Textures/
    <Name>_BaseMap.png        # albedo (sRGB)
    <Name>_MetallicGloss.png  # URP _MetallicGlossMap: metallic RGB, smoothness A
    <Name>_Emission.png       # arcane glow mask (sRGB)
    <Name>_ORM.png            # glTF packing: occlusion R, roughness G, metallic B
    <Name>_Roughness.png      # raw bake, kept for re-packing
    <Name>_Metallic.png       # raw bake, kept for re-packing
  glTF/
    <Name>.gltf, <Name>.bin, textures   # engine-neutral export
```

`enemy_manifest.json` lists every enemy with its role, triangle count, bone count,
bounding height and validation result.

## Importing into Unity (URP 17, Unity 6000.2)

The FBX is authored in metres at Unity scale, standing on the origin and facing +Z,
so the default importer settings are correct. Nothing needs rescaling or rotating.

1. Select the `.fbx`. On the **Model** tab leave Scale Factor at 1 and Convert Units on.
2. On the **Rig** tab set Animation Type to **Generic** and Avatar Definition to
   *Create From This Model*. These are constructs with rigid, non-humanoid skeletons —
   Humanoid will not map them.
3. Create a **URP/Lit** material per enemy and assign:
   - **Base Map** → `<Name>_BaseMap.png`
   - **Metallic Map** → `<Name>_MetallicGloss.png`, with *Source* set to
     **Metallic Alpha** and Smoothness at 1
   - **Emission** enabled, **Emission Map** → `<Name>_Emission.png`, and the emission
     colour set to HDR white with intensity **4** — the baked map is 8-bit and clamps
     at 1, so the glow is scaled in the shader. `materials.EMISSION_STRENGTH` holds the
     matching value used in the review renders.
4. Import settings for the maps: `_BaseMap` and `_Emission` are sRGB;
   `_MetallicGloss`, `_ORM`, `_Roughness` and `_Metallic` must have **sRGB (Color
   Texture) unchecked** — they carry raw data, not colour.

## Rigs

Every mesh is rigidly skinned: one bone per part at weight 1. `Root` sits at the
origin and is the transform to move.

- **SigilWisp** — `Core`, plus `Ring_A/B/C` for the three gyroscope rings (spin them
  on separate axes) and `Tail`.
- **VaultWarden**, **GildedColossus** — full biped chain: `Hips`, `Spine`, `Chest`,
  `Head`, and `Shoulder`/`UpperArm`/`Forearm`/`Hand` and `Thigh`/`Shin`/`Foot` in
  `.L`/`.R` pairs. The Colossus is asymmetric, so its left and right arms differ in
  size and bone length.
- **HexTurret** — `Base`, `Column`, `Head` (yaw) and `Barrel` (pitch). Drive the last
  two to track a target.
- **ArcRevenant** — `Hips`, `Spine`, `Chest`, `Head`, arm chains, and `Sigil` for the
  orbiting rings. It hovers: its geometry starts above `z = 0`, so do not snap it to
  the ground.
